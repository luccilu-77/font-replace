# Photoshop 专业图层架构

本文件规定字体替换 PSD 的图层命名、合并、分组和数量控制。目标是让设计师接手文件后能快速找到文字、直接编辑，并避免“一个字一个图层”的低质量拆分。

## 核心原则

- 一个语义文字块优先对应一个 Photoshop 原生 `TEXT` 图层。
- 图层名直接使用该层文案，例如文字内容为“寻找”，图层名就是 `寻找`。
- 文案过长时截断，不把整段长文塞进图层面板。
- 同一行、同一竖列、同一文本框内字体与样式一致的文字必须合并。
- 只有字符确实需要独立变形、独立颜色、沿路径排列、被主体分段遮挡或使用不同字效时才拆层。
- 图层数量由语义块决定，不由字符数量决定。

## 图层命名

文字图层按以下顺序命名：

1. 读取 `textItem.contents` 对应的真实文案。
2. 将换行、制表符和连续空白压缩为一个空格。
3. 默认最多保留 20 个字符；超过时保留前 19 个字符并加 `…`。
4. 同名图层按出现顺序追加 `-02`、`-03`，同时保持总长度不超过限制。
5. 不使用 `10-editable-*`、`text-1`、`图层 12` 等无法从图层面板识别内容的名称。

示例：

| 文案 | 图层名 |
| --- | --- |
| 寻找 | `寻找` |
| 新登场独特花形杯 | `新登场独特花形杯` |
| 这是一段超过二十个字符的活动规则说明文字 | `这是一段超过二十个字符的活动规则说…` |
| 两个不同区域都写“新品” | `新品`、`新品-02` |

文字效果辅助层使用 `FX-<文字图层名>`；清理底图使用 `00-清理底图`；隐藏参考图使用 `90-原图参考`。

## 合并与拆分

### 应合并

- 横排标题、横排副标题和一整段说明文字。
- 单列竖排中文，例如“新登场独特花形杯”应使用一个竖排文本框，不拆成九个单字层。
- 同一竖列中字体、字号、颜色、字距、旋转和字效一致的连续字符。
- 日期、价格或英文短句在同一基线且样式一致时作为一个图层。

Photoshop 中竖排文字优先设置：

```javascript
textItem.direction = Direction.VERTICAL;
textItem.kind = TextType.PARAGRAPHTEXT;
```

单列竖排直接使用连续文案；多列竖排按视觉列拆成少量文本框，每列一个图层，不按单字拆层。

### 允许拆分

仅在以下情况拆分，并在布局数据的 `split_reason` 中记录原因：

- 每个字符有不同颜色、字号、旋转或位移。
- 文字沿圆弧、波浪或其他路径排列，无法用路径文字或单一文本框稳定复现。
- 主体遮挡需要文字分布在主体前后两个层级。
- 同一文案内部使用不同字体或完全不同的图层样式。
- 原设计明确包含独立跳字动画式节奏，合并会改变视觉效果。

“原图是竖排”“识别结果逐字返回”“实现方便”都不是拆成单字层的理由。

## 推荐图层分组

```text
00-底图
  00-清理底图
10-主标题
20-副标题
30-正文与说明
40-装饰文字
50-文字效果
90-参考
  90-原图参考（隐藏）
```

不要创建只有一个子层且没有管理价值的嵌套组。主标题、副标题、正文和装饰文字较多时再分组；简单海报可以保持扁平结构。

## 布局字段

每个文字块建议包含：

```json
{
  "text": "新登场独特花形杯",
  "block_id": "right-vertical-slogan",
  "role": "副标题",
  "orientation": "vertical",
  "bbox": [1000, 90, 55, 340],
  "layer_name": "新登场独特花形杯",
  "layer_group": "20-副标题",
  "split_reason": null
}
```

- `block_id`：同一语义块的稳定标识；OCR 若逐字输出，先按此字段合并。
- `orientation`：`horizontal` 或 `vertical`。
- `layer_name`：由文案生成的 Photoshop 图层名。
- `layer_group`：图层面板分组。
- `split_reason`：只有确实拆层时填写。

运行 `scripts/prepare_photoshop_layers.py` 可以按 `block_id` 合并逐字记录、生成截断后的唯一图层名，并输出图层数量审计报告。

## 交付前审计

- `TEXT` 图层数应接近语义文字块数量。
- 连续竖排文字不得出现无理由的单字层序列。
- 所有文字层名称应能在图层面板直接识别内容。
- 同名层必须带稳定序号。
- 每个拆分层都要能说明 `split_reason`。
- 隐藏一个文字层时，只消失对应语义文字块，不应只消失其中一个普通字符。
